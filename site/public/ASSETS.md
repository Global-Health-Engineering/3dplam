# Site assets

Everything here is committed and served directly. Renders and figures are
regenerated by scripts in `tools/`; photographs and video are supplied.

## photos/, photographs of the printed device

| File | Shows | Source |
|---|---|---|
| `manifold-assembled.webp` | Assembled manifold, printed in ABS | supplied |
| `manifold-in-use.webp` | Loaded membrane and syringe attached, mid-filtration | supplied |
| `base-with-filter-support.webp` | Base with the strand-mesh filter support seated | supplied |
| `filter-support-strand-mesh.webp` | Strand-mesh filter support close up, in-air printed strands visible | supplied |

Converted from PNG to WebP at quality 82 and resized for web (17 MB → 0.8 MB).

## video/

| File | Shows |
|---|---|
| `base-printing-timelapse.gif` | Timelapse of the base printing. 720 × 720, 86 frames, 8.6 s at 10 fps, 8.5 MB. Author-supplied; loops without interaction |

Use a plain `<video>` element with `muted`, `loop`, `playsinline` and
`preload="metadata"`. It requires no third-party player and no external
hosting.

## models/, regenerated by `tools/render_parts.py` (requires Blender)

glTF binaries for the click-to-open 3D viewer in `Device.astro`, exported
from the same Blender scene as the matching `renders/*.png`, so each part
is the same colour and the same shape in both. Each `.glb` pairs with the
render of the same name.

| File | Triangles | Size |
|---|---|---|
| `assembly-exploded.glb` | 79 k | 1.7 MB |
| `membrane-clamp.glb` | 75 k | 2.0 MB |
| `filter-support-section.glb` | 10 k | 0.5 MB |

The base arrives from CAD at 362 k triangles, which is far too heavy to
ship: `render_parts.py` reduces it to a 60 k budget for the web copy only,
after the render is made. Planar dissolve does most of that (362 k → 147 k
with no change to the silhouette, because the removed edges lay inside
flat regions); collapse decimation covers the rest.

These are fetched only when a reader clicks a render, never on page
load, and so do not affect how fast the page opens.
